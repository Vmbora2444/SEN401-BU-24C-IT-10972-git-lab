1. Repository: A project folder that also has saved history. 
2. Commit: Recorded snapshot of my folder. 
3. Staging Area: Where all my changes wait. 
4. Push: Uploads commits from my computer to GitHub. 
5. Branch: A private independent area that permits me to make changes without altering the main folder. 
6. Pull Request: Asking for approval to merge my changes. 
7. Merge: Joining approved changes. 
8. Merge Conflict: This is where two branches change the same line and Git can't choose. 
9. Pull vs Fetch: Pull merges(joins) into the branch I'm currently on. Then Fetch downloads new changes but leaves my files unchanged. 
10. Distributed: Everyone has the full history on their own computer, so not one server has the only copy. 
11. Git hub helps track things and control things.
